# Sistema de Conversão de Unidades

Projeto da disciplina de Programação de Sistemas (PS).

## Funcionalidades
- Conversão de temperatura
- Conversão de distância
- Conversão de massa

## Conversões disponíveis
### Temperatura
- °C → °F
- °C → K

### Distância
- km → mi
- km → pés

### Massa
- kg → lb
- kg → g

## Como executar
Rode o arquivo principal:

```bash
python main.py
